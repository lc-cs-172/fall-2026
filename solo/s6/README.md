# Assignment #6: Defining Objects

This assignment is meant to give you practice defining objects.

You will define one class:

* `Cursor` in the file `cursor.py`

The class should be written in proper object-oriented style, including:

* An initializer
* Methods required by the tests

I'm providing you with a template of `cursor.py` as well as the unit tests that
need all to pass for this assignment to be considered successful.

Note that there is no `main` program to run here. You're just defining a class
that will be used in the text editor we're building.

## Hints

As advocated by the test-driven development strategy, the initial state of
`cursor.py` is such that all tests *fail*. Your task is to write just enough
code to make each test pass.

Write one method at a time. With each added method, more tests should pass.

There are no loops or recursion required to complete this class; if you're using
those, you're working too hard.

Do *not* modify `cursor_test.py`.
