# Note 03

## Unit testing

Unit testing tests individual parts of a program (e.g., methods or functions).
Unit testing has one big advantage over other forms of testing: It can happen
early.

## Test-driven development

The steps for test-driven development are simple. Below a formulation built
around the notion of functions, but in the general case it is really about
adding any features.

1. Specify a needed function.
2. Write skeleton for that function that returns a single arbitrary value.
3. Build a unit test showing the skeleton function failing.
4. Write the minimum amount of code to make that function work.
