# Node 25

## Some data collections

### Stack

Earlier we talked about the *stack*, a data collection with a *last in, first
out* (LIFO) data movement discipline. A stack supports the following
operations:

* `is_empty` returns `True` if the stack is empty
* `pop` removes and returns the top item from the stack
* `push` adds an item to the top of the stack

### Queue

In contrast to a stack, a *queue* is a data collection with a *first in, first
out* (FIFO) data management discipline. A queue supports the following
operations:

* `is_empty` returns True if the queue is empty
* `dequeue` (pronounced DQ) removes and returns the front item from the queue
* `enqueue` (pronounced NQ) adds an item to the back of the queue
